
# Java Exercises

This repository contains my Java exercises and small projects created while learning and improving my programming skills.

## Projects

### Guess Number

A simple console game where the user tries to guess a randomly generated number between 1 and 100.

The program:

* Generates a random number
* Reads the user's guesses
* Tells the user if the guess is too high or too low
* Counts the number of attempts

### Bank Account

A simple console application that simulates basic bank account operations.

The program allows the user to:

* Check the balance
* Deposit money
* Withdraw money
* Exit the application
### Person

A `Persona` class that models a person with a name and an age.

It shows:

* Private fields and a constructor
* Getters
* A `stampa()` method that prints the person's data
* An `isMaggiorenne()` method that checks if the person is an adult

`TestPersona` creates three people and prints their data and whether they are adults.
